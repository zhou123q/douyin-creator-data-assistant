# DF 对标拆解助手

当前版本：**1.10.3** · [查看本版更新说明](RELEASE_1.10.3.md)

用于整理抖音网页版创作者和作品数据的 Chrome/Edge 扩展。扩展提供对标账号作品分析、自己的账号数据查看、关注博主采集与导出；也可连接本机语音转写和视频片段处理伴侣。

> 当前仓库是源码版，面向愿意手动安装的用户和开发者。它不包含 Windows 便携伴侣安装包、Python 运行环境或语音模型。若你只想快速使用，请先查看本仓库 Releases 是否提供单独的 Windows 伴侣包；没有该附件时，需要按下文从源码安装伴侣。

## 能做什么

- 在抖音网页版查看博主主页作品及页面可读取的互动数据。
- 查看已登录账号主页可读取的作品数据。
- 选择关注博主并采集其近期作品；对已采集作品更新互动数据，避免重复转写。
- 查看采集结果和口播稿，并导出 CSV、JSON 或 TXT。
- 连接本机 faster-whisper 服务进行视频语音转写。
- 连接本机伴侣下载视频或截取视频片段。
- 在配置兼容 AI 服务及 API Key 后使用 AI 分析功能。

数据范围受抖音页面结构、登录状态、账号权限、网络和平台接口影响。播放量等字段并非所有作品都能读取；本项目不承诺获取不可见、受限或账号全部历史数据。请遵守平台规则、著作权和适用法律，仅处理你有权访问的内容。

## 安装浏览器扩展

适用于 Chrome 或 Edge 116 及以上版本。此方式加载源码目录，适合自己使用或测试；浏览器可能提示这是开发者模式扩展。

1. 在 GitHub 仓库页面点击 **Code → Download ZIP** 并解压，或使用 `git clone` 下载仓库。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 打开页面上的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择解压后的仓库根目录，也就是能看到 `manifest.json` 的目录。
5. 打开 `https://www.douyin.com/` 并登录。进入抖音用户主页后，点击浏览器工具栏中的扩展图标使用功能。

如果扩展图标没有显示，可在浏览器扩展菜单中将其固定。更新源码后，在扩展管理页点击扩展卡片上的刷新按钮，再刷新抖音页面。

## 基本使用

### 分析博主作品

1. 在抖音网页打开目标博主主页。
2. 点击扩展图标，进入作品数据页面。
3. 等待作品加载完成；使用页面的排序、搜索、列设置和导出控件整理结果。
4. 如需下载作品或截取片段，使用对应作品行的操作按钮。视频片段处理需要本地伴侣运行。

### 分析自己的账号

1. 先在同一个浏览器中登录自己的抖音账号。
2. 打开自己的抖音主页，再从扩展进入账号数据页面。
3. 等待页面数据读取完成后查看指标和作品列表。

此功能读取当前网页能够访问和呈现的数据，不等同于抖音创作者中心的完整后台报表。若数据没有出现，先确认登录状态、主页是否完整加载，再刷新页面重试。

### 采集关注博主

1. 在扩展中打开 **关注博主更新/采集博主** 页面。
2. 点击 **同步我的关注**，等待关注列表读取完成；也可以按页面提供的入口手动添加博主主页。
3. 选择要采集的博主，再点击采集按钮。
4. 首次采集会获取每位博主最近的若干条作品；之后按上次检查时间查找新作品。已经转写的作品只更新互动数据，不重复转写。
5. 在结果表中检查作品、互动数据和口播稿，再导出 CSV、JSON 或 TXT。

关注列表和任务状态保存在本机浏览器扩展存储中，用于记住所选博主、已处理作品和未完成任务；这不是云端长期内容数据库。浏览器需要保持运行，扩展后台也可能因浏览器休眠、更新或系统关机而暂停任务。遇到失败任务可在页面重试。

## 本地语音转写与视频处理

本地伴侣是可选组件。仅安装浏览器扩展即可浏览和整理数据；需要口播稿自动转写或视频片段下载时，才需要运行伴侣。

### 源码方式安装本地伴侣

要求 Windows、Python 3.12 和网络连接。首次下载依赖和模型需要一定时间与磁盘空间。

1. 安装 Python 3.12，并确保命令行可运行 `py -3.12`。
2. 在本仓库的 `local_asr` 目录打开 PowerShell。
3. 创建虚拟环境并安装依赖：

   ```powershell
   py -3.12 -m venv .venv
   .venv\Scripts\python -m pip install -r requirements.txt
   ```

4. 启动本地伴侣：

   ```powershell
   .venv\Scripts\python run.py
   ```

   也可以在依赖安装完成后运行 `start_dev.bat`。

5. 浏览器打开 `http://127.0.0.1:8765/`。看到本地伴侣状态正常后，保持该窗口运行，再回到抖音页面使用转写或视频处理。
6. 第一次转写时按页面提示下载模型，或从已下载模型目录中选择。

若运行 `start_dev.bat` 提示找不到 `.venv`，说明前面的虚拟环境和依赖安装步骤尚未完成。更完整的源码启动与打包说明见 [`local_asr/README.md`](local_asr/README.md) 和 [`packaging/README.md`](packaging/README.md)。

### 语音模型

默认模型为 [`Systran/faster-whisper-medium`](https://huggingface.co/Systran/faster-whisper-medium)，约 1.43 GB。模型不包含在 Git 仓库中；可以通过本地伴侣页面下载，也可从上游模型页面获取。模型目录默认位于 `local_asr/models/faster-whisper-medium`，也可以通过伴侣页面选择其他目录。

模型许可和使用条件以其上游模型卡及许可文件为准。首次下载可能受网络环境影响；请预留足够磁盘空间。CPU 可运行但速度取决于电脑配置，GPU 加速取决于本机 CUDA 和运行环境配置。本项目不承诺固定转写耗时。

### Windows 免安装包

源码仓库不包含预编译 Windows 伴侣包。若 GitHub Releases 提供 `DF对标拆解助手_Windows.zip` 或类似附件，可按对应 Release 的说明下载解压、启动伴侣，再打开浏览器扩展。若没有该附件，请使用上面的源码安装步骤；不要从非项目发布者渠道下载可执行文件。

## 常见问题

**扩展提示“本地伴侣未运行”**

启动本地伴侣并保持运行，确认 `http://127.0.0.1:8765/` 可以打开；检查没有其他程序占用 8765 端口，然后刷新抖音页面。

**转写按钮不可用或提示模型未下载**

确认本地伴侣运行正常，然后在伴侣页面下载约 1.43 GB 的模型或选择已有模型目录。模型下载失败时，检查网络、磁盘空间和模型目录权限后重试。

**下载或截取视频提示 `Failed to fetch`**

确认本地伴侣运行正常。部分抖音视频地址有时效、来源校验或跨域限制；请从作品页面重新获取地址后再试。截取本身不需要语音模型，但需要本地伴侣完成视频下载和本机裁剪。

**关注同步没有结果或提示扩展后台无响应**

确认已登录抖音且关注列表页面可正常打开；重新加载扩展并刷新抖音页面后重试。关注列表能否读取取决于当前账号权限和抖音页面接口状态。

**播放量或部分互动数据为空**

这通常表示当前页面或接口没有提供该字段，并不一定是插件故障。尝试登录、等待作品加载并刷新；本插件不能保证补齐平台未公开的数据。

**AI 分析无法使用**

AI 分析需要单独配置兼容服务的地址、模型名和 API Key。它不是转写模型，也不会随本项目提供免费额度。不要把 API Key 发布到公开仓库或截图中。

## 隐私与配置

- 浏览器扩展在抖音网页中读取完成页面功能所需的数据；本地伴侣监听地址为 `127.0.0.1:8765`，只面向本机使用。
- 转写模型、下载视频、裁剪结果及伴侣配置保存在本机。除非用户自行配置 AI 服务，转写由本地 faster-whisper 执行。
- 配置 AI 服务后，发送给该服务的数据将受其隐私政策和使用条款约束。
- `local_asr/config.json` 用于本机配置，包含 API Key 时尤其敏感。不要提交该文件、账号 Cookie、视频文件或模型文件。

## 开发与测试

扩展不需要构建步骤，加载仓库根目录即可。运行本地伴侣所需 Python 版本及依赖见 `local_asr/README.md`。

需要 Node.js。运行已有自动化测试：

```text
node --test tests/monitor.test.cjs tests/account_entry.test.cjs tests/self_analytics.test.cjs
```

测试使用模拟数据，不验证抖音真实账号接口、模型下载或 Windows 打包产物。打包本地伴侣的说明见 [`packaging/README.md`](packaging/README.md)。
