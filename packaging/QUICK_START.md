# 快速安装

## 1. 解压

先将整个 ZIP 解压到一个固定目录。不要只移动其中的 EXE；`本地伴侣/df_local_asr/` 目录里的运行文件需要与 EXE 放在一起。

## 2. 安装浏览器插件

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 打开“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本压缩包内的 `浏览器插件` 文件夹。
4. 打开抖音网页版并登录。建议把扩展图标固定到工具栏。

这是开发者模式加载方式，不是 Chrome/Edge 商店的一键安装。浏览器可能显示开发者模式提示；不要删除或移动已加载的 `浏览器插件` 文件夹，否则需要重新加载。

## 3. 启动本地伴侣

双击 `本地伴侣/启动本地伴侣.bat`。第一次启动会在程序目录创建 `config.json`，并自动打开本地状态页。保持出现的黑色窗口运行；关闭它会停止转写和视频处理服务。

视频下载和片段截取可在本地伴侣运行后使用，不需要 Whisper 模型。

## 4. 首次转写

在本地状态页点击“下载转写模型”，下载约 1.43 GB 的 `Systran/faster-whisper-medium`。下载完成后模型保存在本机，后续可复用。模型按其上游页面列出的许可使用：<https://huggingface.co/Systran/faster-whisper-medium>。若模型下载受网络影响，可选择已下载的模型目录。

AI 分析是可选功能，不是本地转写所必需。使用时先关闭伴侣，在 `本地伴侣/df_local_asr/config.json` 中填写 `ai_base_url`、`ai_model` 和 `ai_api_key`，保存后重新启动伴侣；不要把密钥发给他人或提交到公开仓库。

## 常见问题

- **页面显示本地伴侣未运行**：启动伴侣并保持黑色窗口打开，确认 `http://127.0.0.1:8765/` 能访问，再刷新抖音页面。
- **提示端口被占用**：退出已运行的伴侣实例后重开；不要同时运行多个副本。
- **转写不可用/模型未就绪**：在伴侣页面下载模型或选择已有模型目录。模型未就绪不影响视频片段截取。
- **`Failed to fetch`**：确认伴侣在运行；回到作品页面重新打开截取操作，刷新过期视频地址后重试。
- **Windows 安全提示**：仅在确认 ZIP 来自项目的 GitHub Releases 后运行。未签名的个人项目程序可能显示 SmartScreen 警告；不要绕过来源不明文件的安全提示。

## 数据与隐私

本地伴侣仅监听本机 `127.0.0.1`。转写模型、任务临时视频和配置放在本机。配置 AI 服务后，提交给该服务的数据由该服务的隐私政策约束。插件采集能力受抖音登录状态、页面数据和作品权限影响。

## 更新与卸载

更新时先关闭伴侣窗口，再解压新版到新目录；在扩展管理页移除旧的开发者模式插件，然后从新目录的 `浏览器插件` 文件夹重新加载。保存需要的数据后，可删除旧解压目录；模型默认放在伴侣目录下的 `models` 文件夹，删除伴侣目录会一并删除该模型和本地配置。
